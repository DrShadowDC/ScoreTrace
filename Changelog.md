🛠 **Changlog for version 1.5.1**

- baseball/softball: fixed an error in which it not outputting the scores correctly. Error was due to syntax issues of the data point output names. this has been fixed for all sports.
- football: fixed the "ball on" data point. It now correctly shows what yardline the ball is on. Unfortunately, it does not show the direction of play or side of the field so that may be a future feature if the correct index value can be found.
