🛠 Changlog for version 2.0.0

- This is a major UI overhaul by merging the ScoreTrace_RemotePi and ScoreTrace_Local into a unified UI system

- This update also adds the ability to pair the ScoreTrace data with PressRow Apps to automate the clock and playclock within their stats program.

- This update changes how the raspberry pi portion works and makes it much cleaner to build. With that being said, any raspberry pis being used for scoretrace will need to be re-worked slightly. If possible, reflashing the os for a clean build is recommended but not necessary. Please follow the raspberry pi instructions included in this release to get this new version working again.

- this change is mainly due to folder structure, making it much cleaner and easier to setup but unforunately will require reinstalling the files in the correct folder locations as shown in the raspberry pi instructions
